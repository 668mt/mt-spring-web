# mt-spring-generator-starter

启动时扫描实体类，自动创建数据库、表、索引和外键。

支持 **MySQL**、**PostgreSQL**、**SQL Server**。

## 开启

```properties
mt.config.generator.enabled=true
# 实体所在的包，不配置时取 mybatis 的 type-aliases-package
mt.config.generator.packages=mt.spring.biz.entity.po
# 表已存在时，是否自动补齐缺失的字段，默认 false
mt.config.generator.add-missing-column=false
```

## 整体结构

重构后按职责拆成了三层，实体扫描和 SQL 生成分离，新增数据库只需要实现方言：

```
实体类
  │  EntityScanner            扫描注解，翻译成与数据库无关的表结构模型
  ▼
TableDefinition               model 包：列、主键、索引、外键
  │  Dialect                  渲染成 DDL
  ▼
建表 / 建索引 / 建外键
```

| 包 | 说明 |
| --- | --- |
| `core.model` | 与数据库无关的表结构模型（`TableDefinition`、`ColumnDefinition`…） |
| `core.scanner` | `EntityScanner`，实体类 -&gt; `TableDefinition` |
| `core.dialect` | `Dialect` 方言接口 + 各数据库实现 |
| `core.meta` | `SchemaInspector`，基于 JDBC `DatabaseMetaData` 判断库、表、字段是否存在 |
| `utils` | 旧的 `IParser` SPI（已废弃）、`GenerateHelper`、`Jdbc` |

## 各数据库的差异

差异集中在 4 个地方，由方言各自实现：

| | MySQL | PostgreSQL | SQL Server |
| --- | --- | --- | --- |
| 标识符 | 一直加反引号 | 只给保留字加双引号 | 一直加方括号 |
| 自增 | `AUTO_INCREMENT` | `GENERATED BY DEFAULT AS IDENTITY` | `IDENTITY(1,1)` |
| 索引 | `CREATE INDEX` | `CREATE INDEX`（全文索引用 GIN） | `CREATE INDEX` |
| 标识符长度 | 64 | 63 | 128 |

### 为什么 PostgreSQL 不能给驼峰列名加引号

PostgreSQL 会把不加引号的标识符折叠成小写：

```sql
CREATE TABLE notice (userId bigint);   -- 实际存成 userid
SELECT userId FROM notice;             -- 正常，MyBatis 生成的就是这种 SQL
SELECT "userId" FROM notice;           -- 报错，列不存在
```

MyBatis 生成的 SQL 同样会被 PostgreSQL 折叠成小写，所以两边能对上；
一旦生成器加了引号，列名会保留原始大小写，MyBatis 就查不到了。
所以生成器只给 PostgreSQL 保留字（`user`、`order`、`table` 等）加引号。

## 扩展新的数据库

实现 `Dialect` 接口，可以直接继承 `AbstractDialect`：

```java
public class OracleDialect extends AbstractDialect {

	public OracleDialect() {
		super("Oracle", 30, "\"", "\"");
	}

	@Override
	public boolean supports(String driverClassName) {
		return "oracle.jdbc.OracleDriver".equalsIgnoreCase(driverClassName);
	}

	@Override
	protected String getSimpleType(ColumnType type) {
		// ...
	}

	@Override
	protected String getIdentityClause(ColumnDefinition column) {
		return "GENERATED BY DEFAULT AS IDENTITY";
	}
}
```

注册成 Bean 即可：

```java
@Bean
public OracleDialect oracleDialect() {
	return new OracleDialect();
}
```

也可以实现旧的 `IParser` 接口，会被自动适配成方言（`IParserDialectAdapter`），
但旧接口只能生成 SQL 片段，表达不了 PostgreSQL 那种必须单独创建的索引，不推荐再用。

## 事件

建表前后会发布事件，可以监听 `AfterInitEvent` 拿到本次新建的表、索引、字段、外键：

```java
@EventListener
public void afterCreateTable(AfterInitEvent event) {
	event.getNewTables();
	event.getNewIndexes();
	event.getNewColumns();
	event.getNewForeightKeys();
}
```

## 测试

单元测试不需要数据库：

```bash
mvn -pl mt-spring-generator-starter test
```

端到端测试需要一个真实的 PostgreSQL，通过环境变量开启：

```bash
MT_GENERATOR_PG_URL=jdbc:postgresql://127.0.0.1:5432/mt_gen_test \
MT_GENERATOR_PG_USER=postgres \
MT_GENERATOR_PG_PASSWORD=postgres \
mvn -pl mt-spring-generator-starter test
```
